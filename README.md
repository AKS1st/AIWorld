# AIWorld

一个面向「全 AI 驱动世界」的最小可运行模板：
- 在容器中部署，方便扩展与迁移。
- 支持接入多厂商模型与第三方 API。
- 用统一网关把不同能力组合成可编排的 AI 世界。

## 目标

AIWorld 的目标是提供一个基础环境，让 AI 代理可以在受控前提下自由调用资源（模型、工具、服务），并组合出完整工作流。

## 架构（MVP）

```text
+-----------------------------+
|         AI Agents           |
+-------------+---------------+
              |
              v
+-----------------------------+
|      Gateway / Router       |
|  - 统一鉴权                 |
|  - 请求路由                 |
|  - 速率限制与审计           |
+-----+---------------+-------+
      |               |
      v               v
+-----------+   +------------+
| LLM APIs  |   | 3rd APIs   |
| OpenAI    |   | Search     |
| Anthropic |   | Storage    |
| Gemini    |   | Automation |
+-----------+   +------------+
```

## 快速开始（容器部署）

1. 复制环境变量模板：

```bash
cp .env.example .env
```

2. 填入你的密钥（按需填写）：

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY`
- `GEMINI_API_KEY`
- 以及任意第三方 API Key

3. 启动网关容器：

```bash
docker compose up -d
```

4. 查看日志：

```bash
docker compose logs -f gateway
```

## 多厂商与第三方 API 接入建议

- 统一使用网关层做密钥管理和路由，不要让每个 Agent 直接持有所有密钥。
- 按能力域拆分工具：搜索、数据库、自动化、知识库检索。
- 为每个 API 设置限流、重试和超时，避免单点拖垮整个系统。
- 打开审计日志，记录 Agent 调用链，便于追踪和回放。
